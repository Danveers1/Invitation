DANVEER & HARMAN PREET — WEDDING INVITATION
================================================

Upload all files/folders to a GitHub Pages repository.

Files:
- index.html
- style.css
- script.js
- assets/ (contains the generated invitation photos/panels)

The site is English-only and mobile-first.
Opening flow:
1. Tap "Tap to Open"
2. Doors open
3. Scratch the heart
4. Enter invitation
5. Falling petals continue across the entire site

All visual photos in this package are generated from the supplied/generated wedding-invitation reference.
